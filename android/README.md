# Dictate — голосовая клавиатура для Android

Держишь кнопку, говоришь, отпускаешь — текст появляется там, где курсор (WhatsApp, Telegram, почта, браузер — где угодно).
По желанию сначала переводит: говоришь по-русски — вставляется английский, вьетнамский, турецкий или французский.
Распознавание и нейросеть работают на твоём собственном ключе **xAI**; больше никуда ничего не уходит.

**Все кнопки и как пользоваться: [MANUAL.md](MANUAL.md)** — какая кнопка что делает, где что переводится.

## Что умеет

- **Быстро**: звук уходит на сервер, пока говоришь; после отпускания текст готов через ~0,5 с, перевод — через ~2 с.
- **Клавиатура**: держи 🎙 → говори → отпусти. Узкая полоска внизу (~1 см) или полная клавиатура (⤢ / ⌄).
- **Кнопка режима**: RU — как сказано / RU→EN — на английский / RU→VI — на вьетнамский / RU→TR — на турецкий / RU→FR — на французский (тап — следующий).
- **Оформляет длинный текст**: пунктуация, «ёлочки», абзацы; «во-первых… во-вторых…» — нумерованный список. Слова не меняет.
- **Убирает «э», «эм», «ммм»**; «ну», «вот», «как бы» оставляет.
- **Почта голосом**: «иван собака gmail точка ком» → ivan@gmail.com.
- **Свои ссылки**: «вот, держи ссылку на MyShop» → адрес подставится сам.
- **Словарь и замены**: имена, бренды, термины пишутся правильно каждый раз.
- **Память**: короткие факты о тебе, работе, людях — нейросеть учитывает их при оформлении и переводе.
- **Нет интернета** — запись не пропадает: распознается сама, когда сеть появится, придёт уведомление.
- 🕘 **Последние 10 диктовок**, **123** — цифры.
- **Боковая кнопка** (Samsung, долгое нажатие): говоришь, замолчал на 4 с — текст в поле.
- **Плавающая кнопка 🗣 и экран «Переводчик»**: живой голосовой перевод разговора с собеседником.

## С чего начать

Отдай эту папку своему ИИ-агенту (Claude Code, Codex и т. п.) и скажи:

> «Прочитай AGENTS.md. Установи мне это приложение на телефон, основной язык — русский, и веди меня по шагам.»

По шагам вместе с агентом:
1. **Языки перевода**: агент спросит, какие переводы нужны на кнопке режима (сейчас RU→EN, VI, TR, FR; лишние можно убрать, нужные — добавить).
2. Установка Android SDK на компьютер (делает агент).
3. На телефоне **Отладка по USB**: Настройки → Сведения о телефоне → Сведения о ПО → 7 раз нажать «Номер сборки» → Параметры разработчика → Отладка по USB.
4. В настройках Dictate: **Микрофон** — разрешить → **Клавиатура** — включить → выбрать Dictate.
5. **Ключ xAI**: https://console.x.ai → войти → API Keys → Create API key → скопировать → в настройках Dictate нажать строку «Ключ xAI» → вставить.
   В консоли поставь месячный лимит расходов. Ключ вставляй **только** туда — не в чат, не в код, не в файлы.
6. По желанию — **боковая кнопка**: Настройки → Приложения → Приложения по умолчанию → Цифровой помощник → Dictate; затем Настройки → Дополнительные функции → Боковая клавиша → Нажатие и удержание → Цифровой помощник.
   Теперь: долго жмёшь боковую → говоришь → молчишь 4 с → текст в поле.
7. По желанию — **вставка в поле** (Специальные возможности): нужна для боковой кнопки и плавающего переводчика. Настройки → Специальные возможности → Установленные приложения → Dictate → вкл.
   Если серое: Настройки → Приложения → Dictate → ⋮ → «Разрешить ограниченные настройки».
8. По желанию — **плавающая кнопка 🗣**: настройки Dictate → «Плавающая кнопка».
9. **Научи своим словам** (ниже).

## Научить под себя

Dictate запоминает твои слова: имена, бренды, сокращения, адреса почты, ссылки, жаргон для перевода.
Скажи агенту: «Давай научим Dictate моим словам» — как это делается, написано в AGENTS.md, раздел 5.
Раз в 1–2 недели полезно сказать: «посмотри мою историю и найди, где он неправильно распознаёт».

История (всё, что ты надиктовал) хранится только на телефоне и никуда не отправляется.
